FinQuery at a glance

A local-first personal-finance analyst. You drop bank statements, receipts and CSVs into a chat, the assistant imports and categorizes them, and every question is answered from a SQL query it ran, never from the model's memory.

Invariant: numbers come only from executed queries

One explainer per feature and elective, with the code path, the measurements and what is not finished: docs/explainers.

3. Ingestion, from file to categorized bookings

Drop a file in chat or load the sample year. CSV, PDF, photo. Files never enter the prompt.
Read it. CSV presets or a model-proposed mapping confirmed on a card. PDF pages read by the extraction sub-agent with a verbatim guard and balance reconciliation. Receipts read by vision.
Duplicates held aside. Exact and near matches become a card: Keep both or Remove, with a remove-all shortcut.
Categorize. Profile rules, then a merchant dictionary, then the categorizer sub-agent per merchant with a confidence.
Ask what is unsure. Question cards in the same chat. Answers become rules and apply in code before the model speaks.
Fix anything later. Transactions page, splits, changesets with Apply and Discard, Undo on simple edits.

4. Required features and the four electives

Required

  • uv run finquery, one process, models download on first run
  • Chat with history, stop, resume, tabs, create and delete
  • Two selectable models, thinking visible
  • Memory across all chats of a profile
  • Two fine-tuned adapters (query, chart) on the fast slot
  • Video demo

Context management

  • Profiles as isolation
  • Per-turn assembly: summary, memories, taxonomy
  • Rolling summary at 60 percent, editable divider
  • Token badge

Sub-agents

  • Query, chart, categorizer, extraction, memory, web lookup
  • Forced single tool, reasoning first, worked examples
  • Self-check and visible repairs
  • Every query judged against the question, one rewrite

Preference optimization

  • Thumbs on answers and charts
  • Regenerate pair and A/B compare with Pick
  • Feedback page, JSONL export, DPO script

Self-directed web search

  • Only a scrubbed merchant token leaves
  • The model decides search, fetch or finish within a budget
  • Outbound log, cache, off by default
