The one rule

Numbers come from executed queries, never from the model

Chat agent

Reads the question, calls the query tool with a request in words.

→

Query sub-agent

→

SQL guard

→

SQLite

Runs it. Rows come back. Nothing else ever produces a figure.

→

Check pass

Degenerate or off-question result? One revise with the finding.

→

Answer

SQL and rows shown with the words. A typed figure without a query is flagged.

Architecture in one picture

One chat agent, six sub-agents as tools, a guard, a sandbox

Composer

Question cards

Review or import

Flagged rows become a review card. Nothing is written silently.

  • Inherently multimodal: the same local models read images and text.
  • The model points, code verifies. It may not invent a digit.

Elective 4 of 4

Self-controlled web search find a page, read it, quote it

Scrubber

Booking text becomes a merchant token. A person's name is refused. Nothing else ever leaves.

→

Decide

Search, fetch or finish, with reasoning. Up to 4 searches and 3 page reads.

→

Floors in code

At least one search. A page read when a hit is the merchant's own site or Wikipedia. A failed backend is retried free.

→

Finish

A verbatim quote that must occur in what was read. Confidence capped when no source names the merchant.

  • Every request is journaled before it is sent and shown in Settings.
  • Three callers, one loop: the chat tool, the categorizer at import, receipt headers.
  • Cached per profile: the second question about a merchant leaves nothing.
  • Measured: lookups without a search 9 to 0, pages read 0 to 12 after the floors went in.
5:45 to 6:45. The graders' wording is "further than direct results": it visits the page and quotes it, and the log proves what left. Example: Vogtlandbahn or Combi, never a chain the model knows by heart.

The fine-tuning loop in progress

Data

Six synthetic households. 60 writer agents, 60 judges. Kept only by execution: guard, database, an independent second statement, chart self-check, the rendered picture.

→

Frozen benchmark

The shipped household is benchmark-only and unseen in training. Split hashed and frozen before any training row exists.

→

QLoRA, four adapters

query and chart, on E4B and on the 12B. Samples are byte for byte the production prompts. A checkpoint per epoch, quick eval, the best converted to GGUF.

→

Official run

Base against base plus adapter, same benchmark, same runtime. Smoke-tested end to end on an H100.

What we own

Decisions we made, and the ones we reversed on evidence

Kept
Numbers only from executed SQL. Sub-agents as forced tool calls, reasoning first. Every import and decision in the chat. Training equals production: a sample is the exact prompt the sub-agent sends.
Reversed
Qwen3.5 9B chosen on memory, replaced by Gemma 4 12B after the cluster benchmark. Preference optimisation built, measured and removed for multimodal ingestion. "No dashboard" became a dashboard of guarded queries.
Not claimed, on purpose
Sub-agent extra credit. Python code execution (our sandbox runs JavaScript charts). Audio ingestion.
